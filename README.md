# 마지막 정류장 (Last Stop)

30일 안에 공항에 도착하는 버스 생존 운영 웹게임.

전직 소방관 윤재하는 동료 박서윤과 낡은 대형버스로 공항을 향한다. 길 위에서 사람을 만나고, 태울지·내려줄지·약속을 지킬지 결정한다. 달리는 버스는 안전하지만 보급·수리·수면에는 정차가 필요하고, 멈추면 근처의 좀비가 알아챈다.

- **목표:** 30일째 24시까지 공항 대피 접수를 마친다.
- **결말:** 누가 버스에 있었고, 누구를 어디에 내려주었으며, 어떤 약속을 지켰는지를 기록한다.

## 실행 방법

설치할 것은 없습니다. `index.html`을 브라우저(Chrome, Edge)로 열면 됩니다.

## 폴더 구성

```
last-stop/
├─ index.html   게임 실행 파일
├─ css/         화면 스타일
├─ js/          게임 로직 (시계, 이동, 좀비, 사람 등)
├─ data/        수치·장소·인물·사건 데이터 (밸런스 조정은 여기서)
└─ images/      배경·인물·아이콘
```

## 개발 단계

1. 뼈대: 화면 전환, 상태창, 720시간 시계
2. 기본 루프: 이동, 정찰·파밍, 식사, 기력·수면, 엔진·연료
3. 좀비: 정차 판정, 경보, 30분 결정, 포위, 밤 보정
4. 사람: 합류, 초반 사건, 상의, 면담·검사 → 첫 시험판 (초반 3일)
5. 이후: 부탁·평판, 감염, 설비, 30일 전체 지도, 엔딩, 저장, 그림 교체

기준 문서: 통합 게임 기획서 v3.3 (저장소에는 포함하지 않음)
